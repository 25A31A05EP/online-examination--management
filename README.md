Online Examination Management System Using Trees

Project Overview

The Online Examination Management System is a C++ based project that manages student records, examinations, and results using tree data structures.

Objectives

- Manage student registrations.
- Search student records efficiently.
- Create and manage examinations.
- Conduct online examinations.
- Calculate student results.
- Generate student rankings.

Data Structures Used

1. Binary Search Tree (BST): Student record management and searching.
2. AVL Tree: Examination management.
3. Heap: Student ranking based on marks.
4. File Handling: Store student records permanently.

Technologies Used

- Programming Language: C++
- Data Structures: BST, AVL Tree, Heap
- Storage: File Handling

Modules

- Student Registration
- Student Search
- Student Records
- Exam Management
- Online Examination
- Result Calculation
- Student Ranking

How to Run

1. Download the project.
2. Open "main.cpp" in a C++ compiler.
3. Compile and run the program.
4. Follow the menu options.
